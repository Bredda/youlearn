# Documentation YouLearn

Documentation destinée aux personnes qui utilisent la plateforme. Pour installer et développer le projet, voir le
[README](../README.md).

Elle est organisée par rôle. Un même compte peut en cumuler plusieurs : lisez alors chaque section qui vous concerne.

| Vous voulez… | Lisez |
|---|---|
| Vous connecter et comprendre l'interface | [Prendre en main](utilisateur/prise-en-main.md) |
| Trouver un cours à suivre | [Apprenant : le catalogue](utilisateur/apprenant.md) |
| Créer et publier des cours | [Formateur : cours et révisions](utilisateur/formateur.md) |
| Gérer les comptes, les groupes et le journal | [Administrateur](utilisateur/administrateur.md) |
| Comprendre un terme | [Glossaire](utilisateur/glossaire.md) |

## État de la documentation

Ces pages décrivent ce que la plateforme sait faire aujourd'hui. Chaque page signale en fin de texte ce qui n'est pas
encore disponible (lire un cours, progression, parcours…).

## Compléter la documentation

- Une page par sujet, dans `docs/utilisateur/`, en français, écrite pour quelqu'un qui n'est pas développeur.
- Les libellés de l'interface sont cités tels qu'ils s'affichent, en **gras**.
- Ajouter la page au tableau ci-dessus.
- Quand une fonctionnalité change, mettre à jour la page concernée dans le même commit.
